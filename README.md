Dreamcore Web Starter Kit (A-Frame)

목표
- 태블릿에서 바로 실행 가능한 Dreamcore 분위기의 3D 씬을 웹(WebGL)으로 구현합니다. 로블록스나 PC 독립 실행형 엔진 없이도, 브라우저만으로 구동 가능한 시작용 템플릿입니다.

구성
- Entrance / Mirror Hall / Final Door의 3(Scene) 씬
- 간단한 조명/포그로 Dreamcore 분위기 구현
- 모바일에서도 동작하기 쉬운 구조
- Start 버튼으로 시작하고, N 키로 씬 전환 테스트 가능

필수 선행사항
- 최신 크롬/사파리/웹뷰 등 WebGL을 지원하는 브라우저가 필요합니다.
- 네트워크가 불필요합니다(로컬 파일로 열어도 작동합니다).

실행 방법
1) 이 저장소를 태블릿에서 열거나 PC에서 index.html를 열어도 됩니다.
2) Start Dream 버튼을 눌러 시작합니다.
3) N 키를 눌러 씬을 순환해볼 수 있습니다. (데모용)
4) WASD 혹은 방향키로 시나리오를 체험합니다. 모바일의 경우 기기 방향으로 보는 방식이 기본이며, 추후에 모바일 전용 컨트롤을 추가할 수 있습니다.

확장 아이디어
- A-Frame의 컴포넌트를 추가해 간단한 퍼즐/상호작용 추가
- a-sound으로 저음의 분위기 사운드 및 효과음 추가
- 텍스처와 재질을 바꿔 Dreamcore 분위기 강화
- 각 씬에 간단한 트리거를 배치하고, 씬 간 전환 시 카메라 위치를 자동으로 조정하는 로직 확장

필요하신 경우, Dreamcore Starter Kit의 확장 버전(포그 색상 스케일링, 조명 강화, 클릭/터치 인터랙션 개선)을 바로 만들어 드릴게요.
